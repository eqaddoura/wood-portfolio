# مجلد الصور (Cover Images)

ضع هنا صورة غلاف واحدة لكل قسم. الصفحة الرئيسية `index.html` تبحث عن الأسماء التالية بالضبط:

| القسم | اسم الملف المطلوب |
|-------|------------------|
| مدخل أنيق | `entrance.jpg` |
| غرفة ضيوف | `guest.jpg` |
| غرفة معيشة | `living.jpg` |
| طاولة | `dining.jpg` |
| مطبخ أنيق | `kitchen.jpg` |
| غرفة نوم | `bedroom.jpg` |
| حمام | `bathroom.jpg` |

## طريقة الرفع (من المتصفح)
1. افتح هذا المجلد على GitHub: `images/`
2. اضغط **Add file → Upload files**
3. اسحب صورك، وتأكد أن كل صورة اسمها مطابق للجدول أعلاه (بالحروف الصغيرة، بامتداد `.jpg`).
4. اضغط **Commit changes**.

ملاحظات:
- يفضّل صور بعرض حوالي 800 بكسل لتحميل أسرع.
- إذا كانت صورك بامتداد `.png` بدل `.jpg`، أخبرني لأحدّث الأسماء في الصفحة.
- الصفحة تعمل حتى لو لم ترفع كل الصور — الأقسام بدون صورة ستظهر بخلفية أنيقة بدلاً منها.
